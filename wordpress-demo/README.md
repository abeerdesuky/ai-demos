# WordPress Business Website Demo — بيت الإتقان للتشطيبات

موقع شركة تشطيبات وديكور مبني على **WordPress 6.8** (محرر الكتل Gutenberg) بقالب فرعي مخصص `theme-itqan` من Twenty Twenty-Five:
- واجهة عربية RTL بخط Cairo
- قسم رئيسي، خدمات، خطوات العمل، دعوة للتواصل، زر واتساب عائم
- متجاوب بالكامل مع الجوال

> الشركة والبيانات في هذا العرض تخيلية لأغراض التوضيح.
